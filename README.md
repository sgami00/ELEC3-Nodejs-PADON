## How to Run

Make sure Node.js and npm are installed.

Check versions:

```bash
node -v
npm -v
```

### Set 1

**N1 – Project Setup**

```bash
cd set1/n1-setup
npm install
npm start
```

**N2 – Modular Calculator**

```bash
cd set1/n2-calculator
node index.js add 12 8
```

**N3 – File Manager**

```bash
cd set1/n3-file-manager
node index.js list
```

### Set 2

**N4 – Basic HTTP Server**

```bash
cd set2/n4-server
node server.js
```

**N5 – REST-style API**

```bash
cd set2/n5-api
node index.js
```

**N6 – Middleware and API Testing**

```bash
cd set2/n6-middleware
npm install
node index.js
```

## API Testing

The N5 and N6 activities can be tested using Postman or Thunder Client.

Available HTTP methods:

- GET – Retrieve student records
- POST – Add a new student
- PUT – Update student information
- DELETE – Remove a student
